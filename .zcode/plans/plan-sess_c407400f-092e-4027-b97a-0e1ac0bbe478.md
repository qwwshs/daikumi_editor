## 目标

把全局 `chart` / `extra_chart` 完全收进 `ChartService`（模块内 local，不再有全局变量），且**不提供任何返回内部表引用的读取接口**（除 Note/Event 对象按实体返回外）：所有访问走 计数+下标+字段访问器，写入全部走方法，彻底消除绕过路径。

## 一、ChartService 重写（src/services/chartService.lua）

**私有状态**：`local chart = {}`、`local extra_chart = { track = {} }`（module-local，require 缓存保证单例）。

**从 meta.lua 移入的方法**（原 `meta_chart.__index` 上的实现，改操作私有 chart）：
- `update()`：版本迁移/字段补齐（form→from、fake、trans、note_head/wipe_head、track/bpm fill）
- `add(item)` / `delete(item)`：原 `chart:add/delete`（类型分发 + 批量缓冲 + `redo:writeRevoke` + `fNote/fEvent:sort` + `PluginManager:emit`），缓冲表 `meta_chart_push` 一并移入为 local
- `push()` / `pop()`：批量操作（pop 提交缓冲 + 撤销记录 + 排序）

**保留/调整**：`load()`（改操作私有 chart）、`sortNotes()` / `sortEvents()` / `sortBpmList()`、`hasTrack()`、`addNote/deleteNote/addEvent/deleteEvent`（内部用）。

**新增读取 API（全部无表引用外泄）**：

| 类别 | 方法 |
|---|---|
| 生命周期 | `setChart(data)`（深拷贝+`table.fill` 补默认字段）、`save(name)`（内部调 `save(chart, name)`）、`encodeJson()`（dkjson 编码，供旧谱面导入重写文件） |
| 列表（计数+下标） | `getNoteCount()/getNote(i)`、`getEventCount()/getEvent(i)`、`getBpmCount()/getBpm(i)`、`getEffectCount()/getEffect(i)` |
| extra_chart 快速路径 | `getTrackEventCount(trackId, type)`、`getTrackEvent(trackId, type, i)`（替代 getTrackEventsByType 活列表，两个调用点都是倒序遍历，下标访问保语义） |
| 标量/字段 | `getOffset()/setOffset(v)`、`getInfoField(f)/setInfoField(f,v)`、`getPreferenceField(f)/setPreferenceField(f,v)`、`setBpmList(list)`（chart_info 保存用）、`ensureTrack(id)/getTrackField(id,f)/setTrackField(id,f,v)` |
| beat 桥接 | `toBeat(t)` = `beat:toBeat(chart.bpm_list, t)`、`toTime(b)` = `beat:toTime(chart.bpm_list, b)`（消除调用方接触 bpm_list） |

**删除的接口**：`getChart()/getNotes()/getEvents()/getBpmList()/getTracks()/getEffects()/getInfo()/getPreference()/getOffset()/getTrackEventsByType()/getTrackNotes()`（getTrackNotes 已无调用方）。

**唯一豁免（计划内写明）**：`getEffect(i)` 返回 effect 条目本身 —— 全项目只有 `play.lua` 一处只读遍历、且 effect 无任何写入路径，与 Note/Event 同级实体访问。
